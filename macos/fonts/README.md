IBM Plex Mono Regular, Medium, and SemiBold TTFs come from the
[official IBM Plex repository](https://github.com/IBM/plex/tree/master/packages/plex-mono/fonts/complete/ttf)
(version 2.005, retrieved 2026-10-19).

They use the same SIL Open Font License in `../../public/fonts/OFL.txt`, which
the widget build copies into the app alongside the fonts. Registration is
limited to the widget process; it does not install system fonts.
